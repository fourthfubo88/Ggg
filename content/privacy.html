Information involved when you use the site

Searching for a title

As you type in the search box, your browser sends what you've typed directly to Wikidata, a free database run by the Wikimedia Foundation, to suggest matching titles. We don't receive or store those searches. Wikimedia's handling of these requests is covered by the Wikimedia Foundation privacy policy.

Looking up where a title streams

When you pick a title, your browser asks our lookup service for that title's availability. The service runs on Cloudflare Workers. The request contains the title's IMDb identifier, and, like any web request, your IP address and basic browser information. We store availability results by title so we don't have to look the same title up repeatedly; we don't store who asked for them. Cloudflare processes request data as described in the Cloudflare privacy policy.

Availability data comes from the Streaming Availability API by Movie of the Night. Our lookup service contacts it on your behalf; your IP address isn't passed to it.

Hosting

The site's pages are hosted on GitHub Pages. When you visit, GitHub receives your IP address and may log it for security purposes, as described in the GitHub privacy statement.

Site statistics

We may use Cloudflare Web Analytics to count visits and see which pages are popular. It doesn't use cookies or track you across other websites, and we only see totals, not individual visitors.
